# Как опубликовать сайт KVTKA

Что лежит в этой папке:

- `public/index.html` — сам сайт вместе с админкой;
- `netlify/` — серверная часть. Она хранит каталог, фото и заказы, пересылает заказы в Telegram и проверяет пароль админки;
- `package.json` и `netlify.toml` — служебные файлы для Netlify. Их не трогайте.

Понадобятся три бесплатных аккаунта: Telegram-бот, GitHub и Netlify. Всё делается в браузере, программировать не нужно. Займёт примерно 30 минут.

---

## Шаг 1. Создайте Telegram-бота

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, `KVTKA заказы`) и логин, который заканчивается на `bot` (например, `kvtka_orders_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Сохраните его и никому не показывайте.
4. Найдите своего бота и нажмите **Start**, иначе он не сможет вам писать.
5. Узнайте свой **chat_id**: напишите **@userinfobot**, он ответит числом `Id`.
   Если заказы должны видеть несколько человек, создайте группу, добавьте туда бота и @userinfobot и возьмите id группы (он начинается с минуса).

## Шаг 2. Загрузите файлы на GitHub

1. Зарегистрируйтесь на **github.com**.
2. **New repository** → название `kvtka-site` → **Private** → **Create repository**.
3. Нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки: папки `public` и `netlify`, файлы `package.json` и `netlify.toml`.
4. Нажмите **Commit changes**.

Проверьте, что в репозитории есть `public/index.html`, `netlify/functions/order.mjs`, `netlify/lib/common.mjs` и `package.json`.

## Шаг 3. Подключите Netlify

1. Зарегистрируйтесь на **netlify.com** через «Sign up with GitHub».
2. **Add new site** (или **Add new project**) → **Import an existing project** → **GitHub** → выберите `kvtka-site`. Настройки сборки подтянутся сами из `netlify.toml`, поэтому просто нажмите **Deploy**.
3. Откройте **Site configuration** (или **Project configuration**) → **Environment variables** и добавьте три переменные:

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
   | `TELEGRAM_CHAT_ID` | chat_id из шага 1 |
   | `ADMIN_KEY` | **пароль от админки**. Придумайте свой, не короче 10 символов |

4. **Deploys → Trigger deploy → Deploy site**. Переменные начинают работать только после нового деплоя.
5. Вы получите адрес вида `https://kvtka-site.netlify.app`. Это ваш сайт.

## Шаг 4. Первый вход и первая публикация

1. Откройте `https://ваш-сайт.netlify.app/#admin` или нажмите **«Вхід для персоналу»** внизу сайта.
2. Введите пароль из `ADMIN_KEY`.
3. В **Налаштуваннях** укажите телефон, Instagram и часы работы.
4. Нажмите **«Опублікувати зміни»**. Готово: каталог сохранён на сервере.

Проверка: оформите тестовый заказ. Он должен прийти в Telegram и появиться в админке во вкладке «Замовлення». Потом удалите его там.

## Как работать каждый день (с компьютера или телефона)

- **Добавить или изменить товар:** Товари → Новий товар или Редагувати. Фото можно снять прямо камерой телефона.
- **Показать изменения покупателям:** нажмите **«Опублікувати зміни»**. Сайт обновится сразу, без архивов и GitHub.
- Пока вы не нажали «Опублікувати», изменения видны только на этом устройстве. Об этом напоминает жёлтая плашка. Кнопка **«Відкинути»** отменяет ваши правки и загружает актуальный каталог с сайта.
- Если вы правили каталог и с телефона, и с компьютера, при публикации сайт спросит, перезаписывать ли изменения с другого устройства.
- **Заказы** приходят в Telegram и видны во вкладке «Замовлення». Там же меняется статус: Нове → Підтверджене → Доставлене.
- **Остатки:** если у товара включено «Рахувати залишок», сайт сам уменьшает количество после каждого заказа и не даст купить больше, чем есть.

## Как зайти в админку

- ссылка **«Вхід для персоналу»** в самом низу сайта;
- или адрес сайта с `#admin` на конце. Удобно добавить в закладки или на главный экран телефона.

## Свой домен (по желанию)

Купите домен (например, `kvtka.com.ua`) у любого регистратора. Потом в Netlify откройте **Domain management → Add a domain** и следуйте подсказкам. HTTPS Netlify подключит бесплатно.

## Если нужно обновить сам сайт (новую версию `index.html`)

На GitHub откройте папку `public` → **Add file → Upload files** → загрузите новый `index.html` → **Commit changes**. Через минуту Netlify обновит сайт. Товары, фото и заказы при этом не пропадут, они хранятся отдельно.

---

## Важно знать

- **Безопасность.** На опубликованном сайте пароль проверяет сервер: это `ADMIN_KEY`, в коде страницы его нет. Пароль `admin123` в коде работает только когда сайт открыт как файл на компьютере. Сервер сам пересчитывает цены по каталогу, поэтому подменить цену в браузере нельзя.
- **Фото** сейчас с Unsplash (бесплатная лицензия). Лучше постепенно заменить их фотографиями ваших букетов.
- **Бесплатный тариф Netlify** с запасом подходит для небольшого магазина. Актуальные лимиты смотрите на netlify.com/pricing.
