# Памятка: как передать сайт клиенту

## Главный принцип

**Всё, что относится к проданному сайту, оформляется на клиента.** Тогда:

- у клиента свой бесплатный лимит Netlify (300 кредитов в месяц), а ваш не тратится;
- заказы приходят клиенту, а не вам;
- вы не отвечаете за его счета, паузы и пароли;
- сайт юридически и технически его.

| Что | Чьё |
|---|---|
| Telegram-бот для заказов | клиента |
| GitHub (код сайта) | клиента |
| Netlify (хостинг) | клиента |
| Домен (`.com.ua` и т. п.) | клиента |
| Пароль от админки | клиента (вы его не знаете) |
| Демо-версия для показа | ваша |

---

## Перед встречей с клиентом

- [ ] Сайт собран и проверен у вас: название, цвета, тексты, товары, фото.
- [ ] Есть свежий архив сайта или репозиторий с последней версией.
- [ ] Договорились, кто какие аккаунты создаёт. Удобнее всего вместе, по видеосвязи с демонстрацией экрана.

---

## Шаг 1. Клиент создаёт Telegram-бота

1. В Telegram открыть **@BotFather** → `/newbot`.
2. Имя бота, например «Квіти Оксани — замовлення».
3. Логин, заканчивающийся на `bot`.
4. **Токен** клиент сохраняет у себя и **никому не пересылает**, даже вам.
5. Открыть своего бота и нажать **Start**.
6. В **@userinfobot** узнать свой **Id**. Это chat_id.

## Шаг 2. Клиент создаёт GitHub

1. Регистрация на **github.com**.
2. Логин клиента записываете себе: он нужен для передачи кода.

## Шаг 3. Передать код сайта

Выберите один из вариантов.

**Вариант А — Transfer (рекомендуется):**
1. Вы создаёте у себя репозиторий с сайтом клиента, например `oksana-flowers`.
2. GitHub → репозиторий → **Settings** → в самом низу **Transfer ownership**.
3. Вписать логин клиента → подтвердить.
4. Клиенту на почту придёт письмо, он принимает перенос.

**Вариант Б — загрузка в его репозиторий:**
1. Клиент создаёт пустой репозиторий (**Private**).
2. Добавляет вас: **Settings** → **Collaborators** → **Add people** → ваш логин.
3. Вы загружаете туда файлы сайта (через Claude или перетаскиванием с компьютера).

## Шаг 4. Клиент подключает Netlify

1. **netlify.com** → **Sign up with GitHub** (своим GitHub).
2. **Add new site / project** → **Import an existing project** → **GitHub** → выбрать репозиторий.
3. Нажать **Deploy**.
4. **Project configuration** → **Environment variables** → добавить три переменные:

| Key | Значение | Галочка «secret» |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота клиента | ставить |
| `TELEGRAM_CHAT_ID` | chat_id клиента | не ставить |
| `ADMIN_KEY` | пароль от админки, **придумывает клиент**, минимум 10 символов | ставить |

5. **Deploys** → **Trigger deploy** → **Deploy site**, чтобы настройки заработали.
6. **Project configuration** → **General**:
   - **Change project name** → красивое имя, например `oksana-flowers` → адрес `oksana-flowers.netlify.app`;
   - **Powered by Netlify badge** → **Configure** → снять галочку → **Save**;
   - **Visitor access**: проверить, что **Production visibility = Public**.

## Шаг 5. Проверка вместе с клиентом

- [ ] Сайт открывается **с телефона** (в Safari или Chrome, а не внутри другого приложения).
- [ ] Тестовый заказ пришёл **в Telegram клиента**.
- [ ] Клиент вошёл в админку: `адрес-сайта/#admin` + свой пароль.
- [ ] В админке нажата **«Опублікувати зміни»** (первая публикация каталога).
- [ ] В **Налаштуваннях** вписаны телефон, Instagram и часы работы клиента.
- [ ] Тестовый заказ удалён во вкладке «Замовлення».

## Шаг 6. После сдачи

- [ ] Удалить проект клиента из **своего** Netlify, если он там был, чтобы освободить лимит.
- [ ] Отправить клиенту короткую инструкцию: как войти в админку, как добавить товар, как нажать «Опублікувати».

---

## Если клиент хочет обслуживание

- Клиент добавляет вас в свой GitHub: **Settings** → **Collaborators** → ваш логин.
- Вы вносите правки в код, и Netlify клиента сам обновляет сайт.
- Пароли и токены клиента вам при этом **не нужны**.
- Оплата: ежемесячный абонемент за поддержку и правки.

## Важно знать

- **Бесплатный Netlify:** 300 кредитов в месяц на аккаунт. Публикация новой версии кода стоит 15 кредитов, 1 ГБ трафика 20 кредитов. Кнопка «Опублікувати зміни» в админке публикацию кода **не запускает**. Если лимит кончится, денег не спишут, но сайт встанет на паузу до следующего месяца.
- **Vercel** на бесплатном тарифе не подходит для коммерческих сайтов (магазинов).
- **Свой домен** клиент покупает на себя у регистратора и подключает в Netlify: **Domain management → Add a domain**.
- **Никогда** не просите у клиента токен бота или пароль от админки в переписке: всё это он вписывает в Netlify сам.
